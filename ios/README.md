# BlackWater iOS

Manual-share client. When you get a MoMo/bank SMS, long-press it in Messages
→ Share → BlackWater → confirm sender → Save. The message lands in an
iCloud Drive folder that your Mac ingests with `ledger ingest`.

No auto-ingest, no background daemons, no server. Apple doesn't let iOS
apps read SMS in the background, so the share sheet is the ceiling.

## What's in this directory

- `BlackWater/` — the container app (SwiftUI, ~150 lines total)
- `BlackWaterShareExtension/` — the actual share sheet handler
- Two `.entitlements` files preconfigured for iCloud Drive
- Two `Info.plist` files (extension's is here; the container app's is generated by Xcode)

**No `.xcodeproj` is committed** — you generate it in Xcode following the steps
below. This keeps the Swift source diff-friendly and doesn't tie you to a
specific Xcode version.

## Prerequisites

- macOS + Xcode 15+ (uses SwiftUI's `NavigationStack`, iOS 16+ deployment target)
- Free Apple ID (paid Developer account not required for sideload; extension
  will expire in 7 days and need re-installing — a paid account bumps that to 1 year)
- Your iPhone signed into iCloud with iCloud Drive on
- A USB cable *or* your iPhone on the same Wi-Fi as your Mac (for wireless install)

## First-time Xcode setup

### 1. Create the Xcode project

1. Open Xcode → **File → New → Project…**
2. Choose **iOS → App**. Click **Next**.
3. Fill in:
   - **Product Name**: `BlackWater`
   - **Team**: your Apple ID (add one under Xcode → Settings → Accounts if none listed)
   - **Organization Identifier**: `com.tylerasa` (or your own reverse-DNS)
   - **Bundle Identifier** will become `com.tylerasa.blackwater` — remember this
   - **Interface**: SwiftUI
   - **Language**: Swift
   - **Storage**: None
4. Save the project into `ios/` inside this repo. Xcode will make a folder like `ios/BlackWater/BlackWater.xcodeproj`.
5. In Finder, **delete** the auto-generated `BlackWater/ContentView.swift` and
   `BlackWater/BlackWaterApp.swift` inside the new project — you'll replace them
   with the ones committed in this repo.

### 2. Wire in the committed Swift sources

In Xcode's Project navigator (left pane):

1. Right-click the `BlackWater` group → **Add Files to "BlackWater"…**
2. Select all three from this repo: `BlackWaterApp.swift`, `ContentView.swift`, `InboxStore.swift`
3. Check **Copy items if needed = OFF** (they should reference the repo files, not be duplicated)
4. Ensure **BlackWater** target is checked. Extension target doesn't exist yet.

### 3. Add the Share Extension target

1. **File → New → Target…**
2. Choose **iOS → Share Extension**. Click **Next**.
3. Fill in:
   - **Product Name**: `BlackWaterShareExtension`
   - **Team**: same as the app
   - **Bundle Identifier** will become `com.tylerasa.blackwater.BlackWaterShareExtension`
4. Click **Finish**. When prompted **"Activate 'BlackWaterShareExtension' scheme?"** → Activate.
5. In Finder, **delete** the auto-generated `ShareViewController.swift` and `Info.plist`
   inside the new extension folder.
6. Right-click `BlackWaterShareExtension` group in Xcode → **Add Files to…**
7. Add `ShareViewController.swift` and `Info.plist` from this repo, checking only
   the **BlackWaterShareExtension** target.
8. Right-click `InboxStore.swift` (in the `BlackWater` group) → **File Inspector** (right pane)
   → under **Target Membership**, tick **BlackWaterShareExtension** too. This is what
   lets the extension see the same iCloud write helper as the container app.

### 4. Configure iCloud on both targets

For **BOTH** targets (container app + extension), do this:

1. Select the target in the project settings.
2. Go to **Signing & Capabilities**.
3. Click **+ Capability** → **iCloud**.
4. Under **Services**, check **iCloud Documents**.
5. Under **Containers**, click **+** → type `iCloud.com.tylerasa.blackwater`
   (leading `iCloud.` prefix required, then your reverse-DNS bundle ID).
6. When Xcode complains it can't create the container, click **Try Again** —
   it needs to talk to your Apple Developer team.

You should now see `.entitlements` files auto-created by Xcode. Xcode will
generate them; you can either use those or replace them with the committed
`BlackWater.entitlements` / `BlackWaterShareExtension.entitlements` in this
repo (Signing & Capabilities → "All" tab → drag the file in). If in doubt,
use the committed ones — they're the tested config.

### 5. Deployment target

For both targets: **General → Minimum Deployments → iOS 16.0** (or higher).
SwiftUI `NavigationStack` and `.pickerStyle(.menu)` need this.

## Building and installing

### On a plugged-in iPhone

1. Connect your iPhone via USB. Unlock it. If Xcode prompts to trust the
   computer, tap Trust.
2. In Xcode's toolbar, next to Run (▶), pick your iPhone from the device
   dropdown (not a simulator — extensions in the share sheet only appear
   on real devices reliably).
3. Select the **BlackWater** scheme (not the extension scheme) → click **Run**.
4. First run: your iPhone will say "Untrusted Developer". On the phone,
   go to **Settings → General → VPN & Device Management → your Apple ID →
   Trust**.
5. Re-launch from Xcode.

### On a Wi-Fi paired iPhone

Same as above but plug in once first: **Window → Devices and Simulators →
select your phone → check "Connect via network"**. Unplug afterwards; the
device will appear in the run dropdown as long as it's on the same Wi-Fi.

## Verifying end-to-end

1. On the phone: open Messages, long-press any SMS, tap Share.
2. Scroll the second row of the share sheet. If BlackWater isn't there:
   tap **More…** at the end of the row and toggle BlackWater on.
3. Tap BlackWater. The editor should appear with the sender picker and
   body prefilled. Change sender to whatever it should be. Tap **Save**.
4. Open the BlackWater app itself — the "Inbox: N pending" line should
   have incremented.
5. On your Mac, wait ~30 seconds for iCloud sync, then:

```sh
ls ~/Library/Mobile\ Documents/iCloud~com~tylerasa~blackwater/Documents/inbox/
```

You should see the timestamped `.json` file. Then:

```sh
ledger ingest \
  --input ~/Library/Mobile\ Documents/iCloud~com~tylerasa~blackwater/Documents/inbox \
  --db ~/ledger.db
```

## Sideload lifetime

- **Free Apple ID**: the app expires and needs re-running from Xcode every
  **7 days**. Fine for a POC on your own phone.
- **Paid Apple Developer Program** ($99/year): expiry becomes **1 year**.

## Troubleshooting

- **BlackWater doesn't appear in the share sheet.** Tap "More…" at the end
  of the second row and toggle it on. iOS hides new extensions by default.
- **"iCloud Drive is not available" error on save.** On the phone: Settings
  → your Apple ID → iCloud → iCloud Drive → make sure it's on, and scroll
  down the app list to make sure BlackWater is enabled.
- **File written but doesn't appear on Mac.** Wait a minute — iCloud sync
  can be lazy. Check `~/Library/Mobile\ Documents/iCloud~com~tylerasa~blackwater/`
  exists; if not, the container ID in your entitlements doesn't match what
  the OS expects.
- **Extension crashes on Save.** Most likely `InboxStore.swift` wasn't
  added to the extension target. Re-check its Target Membership.
- **App uses different container from what's in Xcode.** Both targets'
  entitlements and `InboxStore.iCloudContainerID` in `InboxStore.swift`
  must all be identical.

## Renaming for your own bundle ID

If you're not `com.tylerasa`, you need to change **three** places to
match your reverse-DNS:

1. Both targets' Bundle Identifiers (Signing & Capabilities)
2. Both targets' iCloud container identifier (`iCloud.<your.bundle.id>`)
3. `InboxStore.iCloudContainerID` in `ios/BlackWater/InboxStore.swift`

Grep-and-replace `com.tylerasa` across the repo and Xcode project.
